# SkillGlider Evaluation System – JavaScript-Based Hackathon Scoring Platform

SkillGlider Evaluation System is a lightweight and interactive web-based marks evaluation platform designed for hackathons, competitions, and technical events.

The goal of this project is to provide a smooth and user-friendly evaluation experience where judges can score participants across multiple categories and instantly generate a final weighted score out of 100.

## Features

- Multi-criteria evaluation system
- 7 weighted scoring categories
- Automatic final score calculation
- Real-time result generation
- Grade classification system
- Clean and responsive UI
- Easy integration into existing websites
- Lightweight frontend-only implementation

---

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Logic: JavaScript-based weighted calculation system

---

## Evaluation Categories

1. Innovation
2. Technical Skill
3. UI/UX
4. Impact
5. Feasibility
6. Presentation
7. Completeness

---

## How It Works

The evaluator enters scores for each category.

The system:
- Applies predefined weights
- Calculates normalized scores
- Computes a final score out of 100
- Generates performance grade automatically
